## Entry

> iPhone Charging Cable (c. 2024) — Primitive energy vine; users performed nightly ritual of untangling before whispering 'please charge' to the glowing rectangle.

## How it works

`main.py` holds the one-line museum label as a constant, validates it (non-blank, single line, 1–200 characters), and writes it as UTF-8 bytes with no trailing newline to `/output/entry.txt`.

## Run

```bash
python3 main.py
cat /output/entry.txt
```
